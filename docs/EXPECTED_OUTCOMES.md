# Expected outcomes assessment

This assessment separates behavior proved through `ulpf serve` from release
evidence that requires external infrastructure. The project implements the
complete single-node reference path and bounded application federation. Native
Linux amd64/arm64 packaging is verified; enterprise recovery and target-site
capacity claims remain conditional.

| Outcome | Status | Evidence and exact boundary |
|---|---|---|
| **a. Preserve complete raw event data without information loss** | Implemented for accepted events | Admission writes the exact occurrence to the filesystem evidence store before committing an `ACCEPTED` receipt. Hash, size, duplicate-occurrence, corruption, and restart tests verify the local boundary. Bytes rejected before durable acceptance, including UDP loss before receipt, are outside the guarantee. |
| **b. Extract and parse source-specific attributes** | Implemented for supported syntax families | The runtime detects and parses JSON, Syslog, CEF, LEEF, XML, CSV, key-value, and declarative RE2 formats while preserving unmapped material. This is syntax-family support, not certification for every vendor dialect. |
| **c. Normalize fields into a common event taxonomy** | Implemented for configured source bundles | The live runtime compiles activated mappings and taxonomies. Two different reference syntaxes normalize to byte-equivalent canonical events, and an HTTP service test proves a `PARSED` mapped revision. Unknown profiles safely use the syntax-only fallback. |
| **d. Maintain traceability between normalized and original events** | Implemented | Receipt, revision, environment/instance origin, bundle/parser/mapping/schema versions, raw SHA-256/size, retained parsed/unmapped fields, and per-canonical-leaf provenance are committed and queryable. |
| **e. Plug-and-play onboarding of new log sources** | Implemented for declarative bundles | Strict non-executable bundles can be scaffolded, tested, signed, validated, installed, listed, activated, or rolled back with compile-before-CAS atomic live routing and no Go changes. Authenticated control endpoints expose lifecycle and durable reprocessing against the exact retained bytes and bundle digest. Native offline Ed25519 verification binds each bundle to configured local publisher trust roots; executable plug-ins are intentionally excluded. |
| **f. Unified visibility across enterprise environments** | Implemented for configured bounded federation | The dashboard aggregates tenant-scoped totals, activity, delivery, and recent events across configured peers, shows origin and stale/unavailable nodes, and proxies cross-node traces without exposing peer credentials. Shared ClickHouse/cluster HA still requires deployment qualification. |
| **g. Efficient SIEM and Data Lake integration** | Implemented for bundled connectors | `ulpf serve` durably reconciles committed envelopes into ClickHouse, authenticated HTTP, NDJSON, and immutable partitioned Parquet connectors with retry, idempotency, leases, dead letters, and bounded batches. ClickHouse can back event queries. Distributed object-store/catalog adapters are outside this reference runtime. |
| **h. AI/ML-ready security and operational analytics** | Implemented data foundation and export | Versioned feature-set and dataset-manifest schemas, deterministic tenant-scoped Parquet export, stable SHA-256 splits, explicit partial-event policy, complete revision/raw/pipeline lineage, quality, issues, and typed feature extraction are implemented. Raw payload bytes are excluded. Training, inference, embeddings, and model-quality claims are outside scope. |
| **i. Reduced parser development effort** | Implemented and demonstrated | Authors reuse bounded syntax parsers or declarative RE2, mappings, taxonomies, fingerprints, semantic fixture verification, immutable installation, runtime source-profile routing, and two complete reference bundles. |
| **j. Deployable in an air-gapped network** | Implemented; native amd64/arm64 clean installs verified | The image-only offline Compose has pulling disabled and a non-masqueraded bridge, packages migrations, validates image identity/layers and mandatory release inventories, and requires an expiring publisher signature against a separately provisioned public key/revocation list. Native hosted engines removed release tags, loaded only signed archives, verified Docker egress control and a rejected external probe, and passed authenticated ingest, query, dashboard, and restart persistence on both architectures in [release run 36581794182](https://github.com/sidd20228/universal_log_framework/actions/runs/36581794182). |
| **k. Container packaged and platform independent** | Implemented for Linux amd64/arm64 | A pinned multi-stage Dockerfile, static non-root/read-only runtime, bundled reference sources, health checks, persistent volumes, migration initialization, hardening tests, SBOM, high-severity vulnerability gate, provenance attestation, and native clean-install jobs are present. Both Linux architectures passed; other CPU architectures and container engines remain unqualified. |

The strict evidence inventory is maintained in
[`EVALUATION_TRACE.md`](EVALUATION_TRACE.md) and can be rerun with
`./scripts/verify-evaluation.sh`.
