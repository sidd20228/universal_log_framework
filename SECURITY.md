# Security Policy

ULPF processes attacker-controlled data. Please report vulnerabilities privately through GitHub Security Advisories for this repository rather than opening a public issue.

Do not include raw production logs, credentials, private keys, access tokens, personal data, or exploit payloads containing sensitive third-party information in a report. Synthetic reproductions are preferred.

The implementation is pre-release. Supported release branches and response targets will be documented before the first tagged release.
